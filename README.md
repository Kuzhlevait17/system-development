# 🎉 AutomaticSender_PSU

**Консольное C++ приложение для автоматической отправки напоминаний о днях рождения сотрудников.**

## 🌟 Функционал
-  Автоматическое определение именинников из БД SQLite.
-  Отправка HTML-писем с поздравлением и картинкой через SMTP.
-  Отложенная отправка в ближайший рабочий день при выходном.
-  Гибкие шаблоны писем (возможность кастомизации).
-  Логирование всех событий (успешные отправки, ошибки).
-  Автозапуск через Task Scheduler (Windows) или cron (Linux).

## 🛠 Технологии
- **Язык:** C++17+
- **Библиотеки:**
  - `libcurl` (SMTP-отправка)
  - `SQLite3` (хранение данных)
  - `OpenSSL` (обеспечение TLS-шифрования при работе с SMTP)
- **Формат данных:** SQLite.
- **Инструменты разработки:**
    - SQLiteStudio — GUI-клиент для удобного управления SQLite-базой.
    - GitHub — для командной работы.

- **ОС:** Windows, Linux.
